##  Project Overview

This repository documents my hands-on journey in building a virtual cybersecurity lab environment using **Kali Linux and Oracle VirtualBox**.

The purpose of this project is to establish an isolated and controlled virtual environment for practical cybersecurity learning, networking, reconnaissance, vulnerability assessment, penetration testing, and security analysis.

This lab will serve as a foundation for future practical exercises and cybersecurity experiments.
